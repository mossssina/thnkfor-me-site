02 · Задача
Новинки есть — анонсов нет

Магазин регулярно пополняет ассортимент, но соцсети не успевают за сайтом. SMM-менеджер не может физически отслеживать каждое новое поступление и делать пост в тот же день.

01
Запаздывание

Товар появляется на сайте, но пост о нём выходит через несколько дней — если вообще выходит. Первые покупатели теряются.

02
Ручная рутина

Менеджер тратит 15–30 минут на каждый пост: найти товар, скопировать фото, написать текст, поставить цену, добавить ссылку и опубликовать.

03
Неполнота

При ручной работе часть новинок теряется: пропущены из-за большого потока, не замечены в каталоге, выложены с опозданием в несколько недель.

04
Непоследовательность

Одни бренды анонсируются активно, другие — редко. Зависит от внимания менеджера, а не от ценности товара для аудитории.

05
Нет системы

Невозможно масштабировать: чем больше ассортимент — тем больше нагрузка на сотрудника. Рост магазина тормозит SMM.

06
Выходные и праздники

В выходные новинки продолжают появляться на сайте, но посты не выходят. Активная аудитория в выходные не получает анонсов.

03 · Решение
Парсер + генератор + автопостинг

Три компонента работают в связке. Парсер следит за сайтом, генератор делает пост из данных товара, автопостинг публикует по расписанию на нужные платформы.

06 · Технологии
Как устроена система

Парсер + база данных + AI-генерация + API соцсетей. Каждый компонент решает свою задачу, вся система работает как единый автономный пайплайн.

Парсер сайта
Мониторинг

Обходит каталог Tennis Point каждые 30 минут. Извлекает: название, фото, цену, описание, бренд, характеристики. Хранит базу известных товаров, определяет новинки по diff.

Claude AI
Генерация текста

По данным товара пишет продающий текст поста. Адаптирует формат под каждую платформу: стиль, длина, хэштеги, эмодзи. Знает теннисную терминологию.

База данных
Учёт товаров

Хранит ID всех товаров, которые уже были распознаны и опубликованы. Исключает дубли. Логирует историю публикаций с временными метками.

VK API
ВКонтакте

Публикует посты с изображением, текстом и ссылкой на товар в паблик магазина. Выбирает оптимальное время публикации по активности аудитории.

Telegram Bot API
Telegram-канал + уведомления

Публикует новинки в Telegram-канал магазина и отправляет уведомления менеджеру о каждой публикации с ссылками для контроля.

Scheduler
Управление очередью

Распределяет публикации по времени: если за день появилось 5 новинок — они выходят равномерно в течение дня, не засоряя ленту разом.

07 · Результат
Ассортимент растёт — нагрузка нет

Система работает автономно. Чем активнее магазин пополняет ассортимент, тем больше контента появляется в соцсетях — без дополнительного труда команды.
