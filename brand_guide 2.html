Clearspace

Minimum clearspace around the logo equals the cap-height of the letter "T". On digital surfaces use 24px minimum on all sides.

Minimum size

Digital: 120px wide minimum. Print: 28mm wide minimum. Below these sizes switch to the stacked variant or monogram.

Color rules

The cursor | and DOT . always appear in #FF3B00 on light backgrounds. On accent or dark surfaces — white or reduced opacity white.

// Donts

Don't stretch

Never distort the logo proportionally. Width and height must scale together.

THNK|FOR.ME

Don't recolor the wordmark

The main letterforms stay #0A0A0A or #FFFFFF. Only the cursor and dot use #FF3B00.

THNKFOR.ME

Don't add effects

No drop shadows, gradients, outlines, or textures on the logo mark itself.

Easing philosophy

Prefer ease-out for entrances. Avoid spring physics — the brand is precise, not bouncy.

Transition speed

UI micro-interactions: 150ms. State changes: 200–300ms. Hero sequences: 600ms–6s loops.

Reduced motion

Wrap all animations in prefers-reduced-motion checks. Cursor blink may stay.

CTA / onboarding

Confident, not arrogant

State facts about capability directly. Never oversell with hyperbole. "We automate your marketing" beats "We revolutionize your marketing."

Start headlines with verbs (RU)

Russian copy leads with action: «Запусти», «Убери», «Думай». Commands feel like system prompts — intentional and on-brand.

Short sentences. Hard stops.

Punchlines under 8 words. Body copy up to 30 words per sentence. No filler — every word earns its place in the system.

// 09 · Do · Don't
Do Square corners on all buttons
border-radius: 0 always. The brutalist edge communicates precision and machine logic — no softening.
→ Get started
Don't Round corners on primary buttons
Rounded buttons feel like generic SaaS product UI. The brand must feel different — architecturally intentional.
Get started
Do Use the cursor | as brand element
The blinking cursor is the brand's signature gesture. It signals human input, machine readiness, and the moment between thinking and doing.
THNK|FOR.ME
Don't Use Signal Orange as large background
#FF3B00 is an accent color — it works in small doses. Filling entire sections with orange dilutes impact and creates visual fatigue.
Full page section in Signal Orange
— This is too much orange
Do Start RU headlines with verbs
Russian language copy opens with an imperative verb. This creates urgency and feels like a system command — aligned with the Human × Machine concept.

Убери лишнее. Оставь результат.

Don't Mix Space Grotesk with serif fonts
The type system is Space Grotesk (human) + IBM Plex Mono (machine). Introducing serifs breaks the Human × Machine logic and creates an inconsistent voice.

// 10 · Avatar System

Фирменный графический знак — × (Human × Machine). Не производная от логотипа, самостоятельная марка. Применяется во всех точках коммуникации кроме основного логотипа.

Знак строится из двух диагональных линий с квадратными торцами · Stroke-weight: 10% от размера холста · Зазор от края: 25%
