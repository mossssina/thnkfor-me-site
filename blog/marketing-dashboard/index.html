Маркетинговый дашборд в Google Sheets: собираем сами

12 сентября 2026 Читать ~11 мин Performance · Google Sheets · API

Единый дашборд из всех рекламных кабинетов, CRM и сайта — мечта маркетолога. Специальные инструменты стоят от 20 000 руб/мес. Но базовый дашборд в Google Таблицах можно собрать бесплатно. Покажем как и из чего.

Что должно быть в маркетинговом дашборде

Маркетинговый дашборд — это не просто красивый отчёт. Это инструмент принятия решений. Хороший дашборд отвечает на три вопроса за 30 секунд: что происходит сейчас, где проблема, что нужно сделать.

Минимальная структура дашборда для малого и среднего бизнеса:

01
Сводка по трафику
Визиты, уникальные пользователи, bounce rate по каналам. Динамика week-over-week. Источники трафика в разбивке.
02
Рекламные расходы и ROAS
Бюджет по каждому каналу, клики, CPL (стоимость лида), ROAS (отдача от рекламных расходов). Сравнение с планом.
03
Конверсии и лиды
Количество заявок, звонков, чатов по каналам. Стоимость конверсии. Динамика за период.
04
Ключевые метрики по соцсетям
Охват, вовлечённость, рост подписчиков, переходы из соцсетей на сайт. Динамика по каждой платформе.

Подключение Яндекс Метрики через API

API Яндекс Метрики — самый простой способ получить данные автоматически. Для этого не нужен навык программирования — достаточно скопировать готовый скрипт на Google Apps Script.

Шаг 1: Получите OAuth-токен в Яндекс OAuth (oauth.yandex.ru). Создайте приложение с правом чтения данных Метрики. Сохраните токен — он нужен для аутентификации в API.

Шаг 2: В Google Sheets откройте Расширения → Apps Script. Вставьте скрипт, который делает запрос к Reporting API Метрики. Базовый запрос выглядит как GET с параметрами: id счётчика, период дат, нужные метрики (visits, pageviews, users) и размерности (source, medium, campaign).

Готовое решение

Если писать скрипт самостоятельно не хочется — используйте коннектор OWOX BI для Google Sheets (бесплатный план до 1 млн строк/месяц). Он подключает Метрику, Директ и ряд других источников через UI без кода.

Подключение рекламных кабинетов: Директ, VK Ads

Яндекс Директ можно подключить двумя способами: через Яндекс Метрику (если аккаунты связаны) или напрямую через API Директа. Первый способ проще: в Метрике данные о расходах Директа уже есть в разделе «Рекламные системы». Просто включите в API-запрос метрики adCost, adClicks, adImpressions.

VK Ads API сложнее для самостоятельного подключения — документация менее дружелюбная. Проще всего использовать готовые коннекторы: Dataslayer, Supermetrics или Funnel.io (платные, но дешевле кастомной разработки). Альтернатива — настроить экспорт отчётов из VK Ads по расписанию в Google Sheets через стандартную функцию экспорта кабинета.

Визуализация в Google Sheets

Сырые данные без визуализации — это таблица, а не дашборд. Google Sheets умеет больше, чем кажется на первый взгляд.

★
Спарклайны — мини-графики прямо в ячейке
Функция =SPARKLINE(диапазон) рисует микро-график динамики прямо в ячейке таблицы. Идеально для сводной строки с трендами по каждому каналу.
★
Условное форматирование для быстрого считывания
Настройте: зелёный — план выполнен, жёлтый — 80–99%, красный — ниже 80%. Сводная страница дашборда читается за секунды без анализа цифр.
★
Диаграммы через Looker Studio (бесплатно)
Подключите Google Sheets к Looker Studio (бывший Data Studio) — бесплатный инструмент Google для красивых дашбордов. Данные из Sheets, графики в Looker Studio.

Автообновление и отправка по расписанию

Дашборд, который нужно обновлять вручную — это не автоматизация. Настройте триггеры в Google Apps Script для автоматического запуска скриптов по расписанию.

В Apps Script: Триггеры → Добавить триггер → Выберите функцию обновления данных → Временной триггер → каждый день в 7:00. Скрипт запустится автоматически, обновит данные, и к началу рабочего дня дашборд уже актуален.

Для отправки отчёта по почте: добавьте в скрипт функцию MailApp.sendEmail() с ссылкой на дашборд или скриншотом ключевых метрик. Руководитель получит письмо в 9:00 с отчётом за прошлый день — без участия маркетолога.
