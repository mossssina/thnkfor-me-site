## Блок 2. Проблемы e-commerce, которые мы закрываем

**H2:** Что тормозит продажи в онлайн-магазине

**Описания товаров — однотипные и слабые**  
«Кроссовки для бега. Материал: синтетика. Подошва: ЭВА». Это не продаёт. Покупатель не понимает, чем этот товар лучше других — и уходит сравнивать на маркетплейс.

**Вопросы покупателей — тормозят менеджера**  
«Подходит для зала?», «Есть в наличии?», «Сколько везти в Новосибирск?» — типовые вопросы, на которые менеджер отвечает вручную сотни раз. Его время нужно на сложные случаи.

**Социальные сети — либо нет, либо публикации раз в месяц**  
500–1000 SKU, а контент делать некогда. Instagram пустой. Новые товары появляются — никто не узнаёт.

**Брошенная корзина — никак не обрабатывается**  
Покупатель добавил в корзину и ушёл. Без напоминания — продажа потеряна.

## Блок 3. Алгоритм AI-контента для e-commerce

**H2:** Как AI создаёт контент для интернет-магазина

**Карточки товаров — массово и убедительно**

Загружаем характеристики товара → Claude API создаёт описание: что выделяет, для кого подходит, как использовать. Не технический список, а продающий текст.

Для магазина с 500 SKU — автоматически. Без копирайтера на каждую позицию.

**AI-визуалы для соцсетей**

Новая коллекция кроссовок, акция на протеин, обзор трекера — контент для Instagram и Telegram генерируется под каждую публикацию в стиле магазина.

**Контент-план под спортивный сезон**

Лыжи — ноябрь. Велосипеды — апрель. Форма для бега — март-апрель, август-сентябрь. Контент-план автоматически учитывает сезонность и даты спортивных событий.

**UGC-механики**  
Просим покупателей делиться фото — AI помогает написать ответ-благодарность и переопубликовать материал. Социальное доказательство без ручной работы.

## Блок 4. Алгоритм автоматизации обработки заказов

**H2:** Как выглядит автоматизированный магазин

**Сценарий: Вопрос о наличии в 22:00**

«Есть беговые кроссовки Asics Gel в 43 размере?»  
Бот проверяет остатки через API магазина. Если есть — даёт ссылку на товар и предлагает оформить заказ прямо в чате. Если нет — предлагает похожий вариант из наличия или сообщает о сроках поступления.

**Сценарий: Брошенная корзина**

Покупатель добавил гантели и ушёл.  
Через 2 часа — сообщение: «Вы добавили товары в корзину. Хотите завершить заказ? Гантели Stein 16 кг сейчас в наличии.»  
Через сутки — второе напоминание со скидкой, если первое проигнорировано.

**Сценарий: Статус заказа**

«Когда привезут мой заказ?»  
Бот автоматически запрашивает номер заказа и выдаёт актуальный статус из системы — без участия менеджера.

**Сценарий: Возврат и обмен**

Покупатель хочет обменять размер.  
Бот собирает данные (номер заказа, причина, желаемый размер), создаёт заявку на обмен и передаёт менеджеру с заполненным контекстом.
